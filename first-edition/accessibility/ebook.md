- 电子书由 [Michael K. Fitzgerald](https://eskur.dev) 转换。
- 本电子书使用出版商 CSS 样式。请确保你的阅读软件已启用出版商样式。即使启用了出版商样式，阅读软件仍可能覆盖这些样式。
- 你的阅读体验可能因设备和阅读软件而异。
- 本 epub 已在 [Calibre](https://calibre-ebook.com/)、[Thorium Reader](https://www.edrlab.org/software/thorium-reader/) 和 [Foliate](https://johnfactotum.github.io/foliate/) 上测试过。
- 桌面和移动应用还可以参见[这份列表](https://github.com/readium/awesome-readium)。
