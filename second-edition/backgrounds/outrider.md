# 佣兵

> 你靠护送商队、追踪逃犯，或为某个目标出刀谋生。你曾是救世主、刽子手、英雄，甚至恶棍。不过，你并不孤身一人：你总有自己的马相伴。

## 姓名

德雷克、赛拉、凯尔、达里厄斯、瓦伦、罗里克、雅拉、芮、塔隆、乔里

## 初始装备

- 3d6 金币
- 口粮（3 次使用）
- 火把（3 次使用）
- 长剑（d10，*笨重*）
- 皮短褂（1 护甲）
- 弩（d8，*笨重*）
- 望远镜

## 你遵守什么个人准则或原则？掷 1d6：

|       |                                                                                                                                                                                                                                                                                       |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | **护及无辜**：无辜者不该为别人的争斗流血。能挡在前面时，你总会挡在前面。获得一面**稳固小圆盾**（+1 护甲）。只要双脚踩在坚实地面上，手持这面盾牌时你就不会被移动。            |
| **2** | **敬惜兵刃**：武器陪你出生入死，也理应得到妥善照料。获得一块**龙骨磨刀石**。花半小时仔细打磨一件武器后，该武器的攻击处于*强化*，直到造成力量伤害为止。                  |
| **3** | **战至最后**：只要战斗还没结束，你就不会先退。获得一支**死亡哨**，1 次充能。吹响后，它的尖啸会令所有听见的人进行意志豁免，失败者会转身逃跑。**充能**：捕获一名垂死战士的最后一口气。 |
| **4** | **敬重死者**：生前的恩怨归生前，死后至少该留一点体面。获得额外 **30gp**。每当敌人死去，你都会在他的眼皮上各放一枚金币，而这笔钱似乎总能补回来。                    |
| **5** | **有诺必践**：答应下来的事，就该做到最后。获得一根风化的**刻痕木棒**。将誓言刻在上面后，木棒会变得坚硬（d8），直到誓言完成。若你违背誓言，木棒会从中折断。                |
| **6** | **有债必偿**：欠下的钱、人情或血债，都该有个交代。你也要求别人如此。获得一本**涂黑账簿**，然后在**羁绊**表上再掷一次。                                 |


## 你的马是什么品种？掷 1d6：

|       |                       |                                                                                                                 |
| ----- | --------------------- | --------------------------------------------------------------------------------------------------------------- |
| **1** | **重型战马**          | 为战争而生的野兽，气势逼人。8 HP，1 护甲，蹄（d10+d10），+2 格。                         |
| **2** | **黑腿花马**          | 健壮且适应性强。**艰难**或**危险**地形的难度降低一级。6 HP。+4 格。                     |
| **3** | **河牙马**            | 强壮得惊人，能够搬运重物。4 HP。+6 格（若载有两人，则只有 +2 格）。    |
| **4** | **花斑矮马**          | 聪明，能理解简单命令，甚至具有危险直觉。6 HP。+4 格。            |
| **5** | **椴木白马**          | 训练有素且敏捷，需要时能完成复杂动作（逃跑时无需进行敏捷豁免）。4 HP。+3 格。 |
| **6** | **流浪雾马**          | 野性十足但速度极快（即使在**艰难**地形中也是如此）。轻装骑行。4 HP。+2 格。                                 |
