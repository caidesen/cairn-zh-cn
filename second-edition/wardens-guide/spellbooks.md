# 法术书

|         |                       |                                                                                                                                                                                                                                                                                              |
| ------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1**   | **黏附**              | 一件物品被极其黏稠的黏液覆盖。*邻近物品会以巨大的力量粘在书上。*                                                                                                                                                                                                                       |
| **2**   | **锚定**              | 一根坚固的金属线从你的手臂上长出，分别固定在两侧 50ft 内的两个点上。*如果将绳子穿过书脊上的铁环，它会变得像大象一样重。*                                                                                                                                                          |
| **3**   | **物体活化**          | 一件物品会尽力服从你的命令。*像黏土一样可塑。书页中会传出孩子般的笑声。*                                                                                                                                                                                                              |
| **4**   | **拟人化**            | 一只动物在一天内获得人类的智力或外貌。*会根据受到的对待发出呜咽、呼噜或低吼。*                                                                                                                                                                                                        |
| **5**   | **奥术之眼**          | 你可以透过一只按照你的命令四处飞行的魔法浮空眼球看见事物。*需要喷一点水才能打开。*                                                                                                                                                                                                     |
| **6**   | **星界牢笼**          | 一件物品在坚不可摧的水晶外壳中被冻结于时空之中。*沉默而抽象的面孔在其中痛苦地尖叫。*                                                                                                                                                                                                  |
| **7**   | **吸引**              | 两件物品进入 10 英尺范围内时，会受到强大磁力的相互吸引。*附近的指南针会徒劳地旋转。*                                                                                                                                                                                                  |
| **8**   | **听觉幻象**          | 你制造出听起来仿佛来自任意方向的幻觉声音。*一天之中会随机产生偶尔不合时宜的声音。*                                                                                                                                                                                                      |
| **9**   | **胡言**              | 一名生物必须大声而清晰地重复你所想的一切。除此之外，它无法说话。*大声读出书中文字时，其他人的话语会变得无法理解。*                                                                                                                                                                          |
| **10**  | **诱饵花**            | 一株植物从地面长出，散发腐肉的气味。*会吸引苍蝇。*                                                                                                                                                                                                                                     |
| **11**  | **野兽形态**          | 你和你的物品变成一只普通动物。*覆盖着厚厚的毛皮，边缘排列着细小的牙齿。*                                                                                                                                                                                                              |
| **12**  | **困惑**              | 在法术持续期间，你选择的一名生物无法形成新的短期记忆。*每次打开时，书中的内容都会移动并改变。*                                                                                                                                                                                       |
| **13**  | **身体互换**          | 你与触碰到的一名生物交换身体。如果其中一具身体死亡，另一具也会死亡。*封面显示最后一个读过它的生物的图像。*                                                                                                                                                                           |
| **14**  | **魅惑**              | 一名你能看见的生物会把你当作朋友。*摸起来很温暖，还散发玫瑰的香气。*                                                                                                                                                                                                                   |
| **15**  | **命令**              | 目标会服从一条不会伤害自己的三个词的命令。*会随着时间变薄，最终永远消失。*                                                                                                                                                                                                            |
| **16**  | **理解语言**          | 你会在短时间内流利掌握所有语言。*会滴落字母，将接触到的一切染上污渍。*                                                                                                                                                                                                                |
| **17**  | **泡沫之锥**          | 浓密泡沫从你的手中喷出，覆盖目标。*海绵般湿润，残留着肥皂。*                                                                                                                                                                                                                            |
| **18**  | **控制植物**          | 附近的植物和树木会服从你，并获得缓慢移动的能力。*书脊上长出叶子，还散发着淡淡的腐败气味。*                                                                                                                                                                                           |
| **19**  | **控制天气**          | 你可以随意改变天气类型，但无法进一步控制天气。*极其耐受火焰和水的伤害。*                                                                                                                                                                                                              |
| **20**  | **治疗伤口**          | 每天为你能触碰到的一名生物恢复 1d4 STR。*散发醋和百里香的气味。使用后会变红。*                                                                                                                                                                                                        |
| **21**  | **失聪**              | 附近的所有生物都会失聪。*附近的乐器偶尔会发出声音，仿佛在抗议。*                                                                                                                                                                                                                       |
| **22**  | **探测魔法**          | 你能看见或听见附近的魔法灵光。*附近有人使用魔法时，它会摸起来发热。*                                                                                                                                                                                                                    |
| **23**  | **拆解**              | 你身体的任何部位都可以随意拆下和装回，不会造成疼痛或伤害。你仍然可以控制它们。*会再生所有被撕破或涂毁的书页。*                                                                                                                                                                         |
| **24**  | **伪装**              | 只要保持类人生物的形态，你就可以随意改变一个角色的外貌。试图复制其他角色时会显得诡异。*表面是一面完美的镜子。*                                                                                                                                                                         |
| **25**  | **错位**              | 一件物品看起来最多偏离实际位置 15ft。*里面有时会塞入一些线头、衣物和叶子。*                                                                                                                                                                                                            |
| **26**  | **地震**              | 地面开始剧烈震动。建筑物可能受损或倒塌。*沙子从书角不断流出，仿佛永远不会停止。*                                                                                                                                                                                                      |
| **27**  | **弹性**              | 你的身体可以拉伸至 10ft。*散发太妃糖的气味，非常柔韧。*                                                                                                                                                                                                                                 |
| **28**  | **元素之墙**          | 一面 50ft 长、10ft 高的笔直冰墙或火墙从地面升起。*使用后，皮肤和更温暖的物质会粘在上面。*                                                                                                                                                                                             |
| **29**  | **偷窃**              | 一件可见的物品传送到你的手中。*有时可以在书页之间发现盟友珍爱的物品。*                                                                                                                                                                                                                 |
| **30**  | **鱼肺**              | 目标可以在水下呼吸，直到再次浮出水面。*散发浓烈的海洋气味。会吸引野生动物。*                                                                                                                                                                                                           |
| **31**  | **闪光**              | 一颗明亮的能量球向天空射出一道光迹，向朋友或敌人暴露你的位置。*在完全黑暗中会发出微光。*                                                                                                                                                                                             |
| **32**  | **雾云术**            | 浓雾从你身边扩散开来。*浸入水中时，书最终会将所有液体变成蒸汽。*                                                                                                                                                                                                                       |
| **33**  | **狂乱**              | 附近的一名生物爆发出暴力狂乱。*粗糙的砂纸封皮会摧毁它接触到的任何书籍。*                                                                                                                                                                                                            |
| **34**  | **界门**              | 一扇通往随机位面的传送门开启。*中央刻着一个巨大的洞，通向虚空。投入其中的物品再也不会出现。*                                                                                                                                                                                         |
| **35**  | **重力转移**          | 你可以改变重力方向，但只能影响自己。*会附着在附近最大的物品上。*                                                                                                                                                                                                                       |
| **36**  | **贪婪**              | 一名生物产生占有你选择的可见物品的强烈冲动。*封面会根据持有者改变，微妙地暗示其最深层的欲望。*                                                                                                                                                                                       |
| **37**  | **加速**              | 你的移动速度变为三倍。*打开时书页会疯狂翻动。可能造成纸张割伤。*                                                                                                                                                                                                                        |
| **38**  | **憎恨**              | 一名生物对另一名生物或团体产生深切的憎恨，并渴望摧毁他们。*长期接触这本书可能导致猜疑、偏执和对他人的不信任。*                                                                                                                                                                        |
| **39**  | **听见低语**          | 你可以清楚地听见微弱的声音。*此后的一小段时间内，读者的声音会被放大。*                                                                                                                                                                                                                |
| **40**  | **悬浮**              | 一件物品在离地 2ft 的位置无摩擦地悬浮。它最多可以承载一名类人生物。*掉落时会漂浮。*                                                                                                                                                                                                     |
| **41**  | **催眠**              | 一名生物进入恍惚状态，并会如实回答你提出的一个是非问题。*醒目的螺旋纹装饰着封面。*                                                                                                                                                                                                    |
| **42**  | **冰冷之触**          | 厚厚的冰层覆盖被触碰的表面，半径最多 10ft。*需要戴手套。不可燃。*                                                                                                                                                                                                                      |
| **43**  | **辨认主人**          | 你触碰的物品上方会出现字母，拼出该物品所有者的姓名（如果有所有者）。*书的内页列出它上一任主人的姓名。*                                                                                                                                                                                |
| **44**  | **照明**              | 一盏浮空的灯会按照你的命令移动。*置于光线中时，书页会变成一道绚丽彩虹组成的棱镜。*                                                                                                                                                                                                     |
| **45**  | **隐形系链**          | 彼此相距 10ft 内的两件物品无法被移动到相距超过 10ft 的地方。*书页没有用胶水或线缝在一起，却依然保持相连。*                                                                                                                                                                            |
| **46**  | **敲击**              | 附近的一把世俗或魔法锁会发出巨响并解锁。*上锁。新的持有者会在下一顿饭后“变出”钥匙。*                                                                                                                                                                                                   |
| **47**  | **跳跃**              | 你可以跳到 10ft 高处，一次。*被投掷时，它会一直飞下去。*                                                                                                                                                                                                                               |
| **48**  | **液态空气**          | 你周围的空气变得可以游泳。*会自行漂浮，弹开接触到的一切。*                                                                                                                                                                                                                             |
| **49**  | **魔法阻尼**          | 附近所有魔法效果的效力减半。*法术书 100ft 内的遗物无法充能。*                                                                                                                                                                                                                           |
| **50**  | **庄园**              | 一座坚固而配备家具的小屋会出现数小时。你可以随意允许或禁止进入。*如果把书留在里面，书和小屋都会永远消失。*                                                                                                                                                                           |
| **51**  | **弹珠狂热**          | 你的口袋装满弹珠，并会每 30 秒重新装满。*受到摇晃时会发出顽皮的哗啦声。*                                                                                                                                                                                                             |
| **52**  | **假面**              | 一个角色的外貌和声音变得与被你触碰的角色完全相同。*长时间使用会使持有者形成无意识却明显的抽搐动作。*                                                                                                                                                                                   |
| **53**  | **缩小**              | 你触碰的一名生物缩小到老鼠大小。*文字大得荒谬而可笑。*                                                                                                                                                                                                                                |
| **54**  | **镜像**              | 一个你的幻象复制体出现，并受你控制。*随着时间推移，持有者开始怀疑谁是原本的自己，谁是复制体。*                                                                                                                                                                                        |
| **55**  | **镜行**              | 一面镜子变成通往另一面、你今天照过的镜子的门户。*除非持有者礼貌地敲击封面，否则不会打开。*                                                                                                                                                                                            |
| **56**  | **多臂**              | 你暂时获得一条额外手臂。*使用后，施法者会被幻肢综合征折磨一天。*                                                                                                                                                                                                                        |
| **57**  | **黑夜球体**          | 一个宽 50ft、显示夜空的黑暗球体出现在你面前。*封面上显示着一座醒目的星座。*                                                                                                                                                                                                            |
| **58**  | **物体化**            | 你变成一件尺寸介于大钢琴和苹果之间的无生命物品。*使用后，持有者会经历数日强烈的幻觉性错视。*                                                                                                                                                                                          |
| **59**  | **渗流形态**          | 你变成一团活着的凝胶。*会缓慢滴落酸液，最终侵蚀它接触到的一切。*                                                                                                                                                                                                                       |
| **60**  | **安抚**              | 你附近的一名生物会厌恶暴力。*散发茉莉和熏香的气味。会吸引儿童。*                                                                                                                                                                                                                       |
| **61**  | **通道**              | 在木头、石头或砖块中创造一条临时通路。*放在书顶的物品必然会从另一侧掉出去。*                                                                                                                                                                                                           |
| **62**  | **恐惧症**            | 附近的一名生物会恐惧你选择的某件物品。*随着时间推移，令人萦绕不去的抽象艺术开始填满书页。*                                                                                                                                                                                            |
| **63**  | **陷坑**              | 地面上出现一个宽 10ft、深 10ft 的坑。*书脊中可以安全地存放一枚标准岩钉。*                                                                                                                                                                                                              |
| **64**  | **原始激涌**          | 一名生物迅速进化为其物种未来的形态。*持有者会被自己祖先的奇异幻象纠缠。*                                                                                                                                                                                                               |
| **65**  | **推/拉**             | 任何大小的物品都会以一个人的力量被直接拉向你，或被直接推离你。*施加在书上的任何力量都会被可笑地放大。*                                                                                                                                                                                 |
| **66**  | **起死回生**          | 一具骷髅从地面升起，为你服务。它极其愚蠢，只能服从简单命令。*每次使用后，持有者都会越来越着迷于骨头。*                                                                                                                                                                                 |
| **67**  | **召回灵魂**          | 附近一具尸体的灵魂显现，并会回答 1 个问题。*答案（但不是问题）会永远铭刻在书页中。*                                                                                                                                                                                                    |
| **68**  | **读心**              | 你可以听见附近生物的表层思想。*长期持有会让读者误以为他人的思想是自己的。*                                                                                                                                                                                                             |
| **69**  | **排斥**              | 两件物品在 10ft 内会受到强大磁力的相互排斥。*由两条强力带子闭合，却会在不合时宜的时候弹开。*                                                                                                                                                                                         |
| **70**  | **窥探**              | 你可以透过今天早些时候触碰过的一名生物的眼睛看见事物。*使用后，持有者的眼睛会变成乳白色，持续一小时。*                                                                                                                                                                               |
| **71**  | **雕塑元素**          | 无生命材料在你手中表现得像黏土。*接触木头或布料时会缓慢腐朽。埋入泥土或浸入水中即可恢复。*                                                                                                                                                                                             |
| **72**  | **感知**              | 选择一种物品（钥匙、黄金、箭、壶等）。你可以感知最近的同类物品。*这本书的上一任主人始终知道它当前的位置。*                                                                                                                                                                             |
| **73**  | **盾牌**              | 你触碰的一名生物在一分钟内受到保护，不会受到世俗攻击。*用生锈的环甲装订，非常沉重。手持时提供 +1 护甲。*                                                                                                                                                                              |
| **74**  | **遮蔽**              | 你触碰的一名生物在移动前保持隐形。*除了这本书当前的持有者，其他人都无法看见。*                                                                                                                                                                                                           |
| **75**  | **交换**              | 你能看见的两名生物瞬间交换位置。*如果书被偷走但尚未读过，它会重新出现在主人上次将它放下的地方。*                                                                                                                                                                                      |
| **76**  | **巧手修复**          | 你对一件无生命物品进行小修。*用一百本书的羊皮纸缝制而成，没有两页完全相同。*                                                                                                                                                                                                           |
| **77**  | **睡眠**              | 一名你能看见的生物陷入浅睡。*像枕头一样柔软，却只能带来断断续续的睡眠。*                                                                                                                                                                                                               |
| **78**  | **湿滑**              | 30ft 半径内的每个表面都变得极其光滑。*拿取时必须戴手套，否则书会以极其滑稽的方式掉落。*                                                                                                                                                                                               |
| **79**  | **烟雾形态**          | 你的身体变成可以控制的活烟雾。*散发篝火气味。书页无法被烧毁，但对潮气非常敏感。*                                                                                                                                                                                                       |
| **80**  | **嗅探**              | 你可以闻到哪怕最微弱的气味痕迹。*散发只有持有者能察觉的强烈气味。*                                                                                                                                                                                                                     |
| **81**  | **熄灭**              | 你能看见的任何世俗光源都会立即熄灭。*如果长时间留在同一地点，附近的光源最终会变暗，然后彻底熄灭。*                                                                                                                                                                                   |
| **82**  | **分类**              | 无生命物品会按照你设定的类别自行分类。*掉落或投掷后会自行摆正。*                                                                                                                                                                                                                       |
| **83**  | **法术锯**            | 一把旋转的刀刃从你的胸口飞出，清除沿途的所有植物材料。除此之外它没有危害。*用染色皮革包裹，至少每月应上油一次。*                                                                                                                                                                      |
| **84**  | **蛛行**              | 你可以像蜘蛛一样攀爬表面。*每次使用前都必须拨开新结的蛛网。它们很难清除。*                                                                                                                                                                                                             |
| **85**  | **群聚**              | 你变成一群乌鸦、老鼠或食人鱼。你只能受到*爆发*攻击的伤害。*很容易被分成十二个独立部分，这些部分会随着时间缓慢地彼此靠近。*                                                                                                                                                             |
| **86**  | **目标诱饵**          | 你触碰的一件物品会成为附近任何法术的目标。*会吸引各种魔法生物、法术泄漏和窥探。*                                                                                                                                                                                                        |
| **87**  | **心灵遥控**          | 你可以用意念移动 1 件不超过 60lbs 的物品。*持有者只需通过意念下令就能召回法术书（WIL 豁免，否则之后陷入匮乏）。*                                                                                                                                                                      |
| **88**  | **心灵感应**          | 两名生物无论相隔多远，都能听见彼此的思想。*持有者能听见（但无法回应）最后一个持有过它的人的思想，反之亦然。*                                                                                                                                                                            |
| **89**  | **传送**              | 一件你能看见的物品或一个你能看见的人，在 50ft 半径内从一个地点传送到另一个地点。*可以摧毁它来制造通往另一维度的传送门。*                                                                                                                                                                |
| **90**  | **荆棘林**            | 一片宽达 50ft、由树木和茂密灌木组成的灌木丛突然生长出来。*缠绕着藤蔓，每次使用时都必须再次摧毁。*                                                                                                                                                                                     |
| **91**  | **时间控制**          | 50ft 气泡范围内的时间减慢或加快 10%，持续 30 秒。*外观交替呈现出不可思议的古老感或刚刚写成的样子。*                                                                                                                                                                                    |
| **92**  | **真视**              | 你能看穿附近所有幻象。*无法被魔法隐藏，显眼得像肿痛的拇指。*                                                                                                                                                                                                                             |
| **93**  | **涌泉**              | 一股海水泉涌现。*坚硬的皮革装订上结满盐和活着的藤壶。*                                                                                                                                                                                                                                 |
