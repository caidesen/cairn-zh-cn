# 核心规则

## 属性

三项**属性**分别用于不同的情况。（见下文的**豁免**。）

- **力量**：用于需要身体力量的豁免，例如抬起闸门、掰弯铁栅栏、抵抗毒素等。
- **敏捷**：用于需要身手、速度、反应、闪避、攀爬、潜行、保持平衡等能力的豁免。
- **意志**：用于说服、欺骗、审问、恐吓、魅惑、挑衅、操纵法术等豁免。

## 豁免

- 豁免用于判定角色能否避免危险行动的后果。角色掷 1d20，并将结果与相应属性比较。结果等于或低于该属性则成功，否则失败。掷出 1 总是成功，掷出 20 总是失败。
- 如果两个对手都试图压制对方，由风险更高的一方进行豁免。
- 如果两个角色需要共同完成一个行动，由风险更高的一方进行豁免（通常是相关属性最低的角色）。

## 治疗与恢复 {#healing--recovery}

- 休息片刻并喝点水可以恢复损失的 HP，但也可能让队伍暴露在危险之中。绷带可以让重伤角色稳定下来。
- 属性损失（见**重伤**）通常休养一周即可恢复；这期间需要治疗者或其他合适的专业人士协助。
- 有些治疗服务是免费的；魔法手段或更快速的恢复方式则可能需要付出代价。

## 匮乏与疲劳

- 缺少关键需求（例如食物或休息）的玩家角色处于**匮乏**状态。匮乏状态持续超过一天的角色，每天要在物品栏中增加 1 点**疲劳**。匮乏状态下无法恢复 HP、属性，也无法恢复被**疲劳**占用的物品栏格。
- 施放法术或游戏世界中的事件也可能迫使玩家角色增加**疲劳**。每点疲劳占用一个物品栏格，直到玩家角色得以恢复（例如在安全地点睡一整晚）才会消失。
- 如果角色被迫在物品栏中增加**疲劳**，但没有空余格子，就必须从物品栏中丢弃一件物品。

## 护甲

- 在计算 HP 所受伤害前，从伤害掷骰结果中减去目标的**护甲**值。
- 盾牌和类似护甲会提供额外防御（例如 +1 护甲），但只有在手持或穿戴该物品时才有效。有些物品还会根据游戏情境提供额外益处。
- 玩家角色、NPC 或怪物的护甲值不能超过 3。

## 反应 {#reactions}

当玩家角色遇到对方态度不明显的 NPC 时，守望者可以掷 2d6，并查阅下表：

|         |      |         |      |         |
| :-----: | :--: | :-----: | :--: | :-----: |
|    2    | 3-5  |   6-8   | 9-11 |   12    |
| 敌对 | 警惕 | 好奇 | 友善 | 乐于助人 |

## 士气

- 敌人首次出现伤亡，以及人数损失过半时，必须进行一次意志豁免，以避免逃跑。
- 某些群体可以使用首领的意志代替自己的意志。孤立的敌人在 HP 降至 0 时必须进行豁免。
- 士气不影响玩家角色。

## 雇工

- 冒险队可以招募雇工，借助他们独特的技能、知识和训练来协助远征。
- 要创建一名雇工，请从市场中的[每日雇工](/second-edition/players-guide/marketplace#hirelings-per-day)表选择合适的角色。为每项属性掷 3d6，为 HP 掷 1d6。给予他们与其身份相称的**装备**，然后在角色特征表上掷骰，进一步完善其形象。
- 另一种方式是从[角色创建](/second-edition/players-guide/character-creation)指南中选择合适的[**角色过往**](/second-edition/players-guide/character-creation#backgrounds)和**姓名**。为该角色过往掷骰（或直接从表中选择），然后为口粮、金币、属性、HP 和年龄掷骰。

## 命运骰

- 只要事件结果不确定，或你想模拟随机和偶然因素，就可以选择掷 1d6。
- 结果为 4 或更高通常有利于玩家角色，结果为 3 或更低通常意味着玩家角色运气不佳。

## 战斗

### 轮

- 一个**轮**大约代表游戏世界中的十秒，并由双方轮流行动。每轮先由任何能够行动的玩家角色行动，随后是对手。*双方行动的结果会同时发生。*
- 在*战斗的第一轮*，每名玩家角色都必须进行一次敏捷豁免才能行动。特殊情境、能力、物品或技能可能免除这一要求。豁免失败的玩家角色在本轮*失去行动机会*。
- 接着由对手行动，第一轮结束。下一轮从玩家角色行动开始，随后是对手，如此循环，直到一方被击败或逃跑，战斗结束。

### 行动

角色在自己的回合中可以移动最多 40 英尺，并进行至多一个行动。行动可以是施放法术、攻击、再次移动，或其他合理的行为。每轮，玩家角色都要在掷骰前声明自己要做什么。如果角色尝试危险的事情，守望者会要求合适的玩家或 NPC 进行豁免。

### 攻击与伤害

- 攻击者掷出武器骰，减去目标的护甲，然后将剩余数值从对手的 HP 中扣除。战斗中的攻击自动命中。
- 如果多名攻击者以同一敌人为目标，掷出所有伤害骰，但只保留其中最高的结果。所有行动都会在结算前先声明。
- 如果一次攻击会使玩家角色的 HP 恰好降至 0，请查阅[创伤表](#scars-table)，确定他受到的特殊影响。

### 攻击修正

- 如果角色处于不利位置战斗（例如隔着掩体，或双手被绑），攻击会受到*削弱*，攻击者无论武器伤害骰为何，都必须掷 1d4。徒手攻击总是造成 d4 伤害。
- 如果角色处于有利位置战斗（例如面对无助的敌人，或通过大胆的机动占据优势），攻击会得到*强化*，攻击者可以用 1d12 代替正常的伤害骰。
- 带有*爆发*特性的攻击会影响标示范围内的所有目标，并为每个受影响的角色分别掷骰。这可以是爆炸、巨龙吐息，或陨石撞击。如果不确定能影响多少目标，就掷相关伤害骰，将结果作为目标数量。
- 如果同时使用两把武器攻击，掷出两枚伤害骰，只保留其中最高的结果（用加号表示，例如 d8+d8）。

### 重伤

- 如果伤害使目标的 HP 降到 0 以下，就将超出部分从其力量中扣除。目标必须立刻使用*新的力量值*进行一次力量豁免，以避免受到**重伤**。豁免成功时，目标仍能继续战斗（虽然力量值降低了），并且之后每次受到伤害时都必须继续进行重伤豁免。
- 受到重伤的玩家角色除了虚弱地爬行、挣扎求生之外什么也做不了。如果得到援助（例如绷带），他们会稳定下来。如果不接受治疗，他们会在一小时内死亡。未通过重伤豁免的 NPC 和怪物视为死亡，具体由**守望者**裁定。此外，一些敌人在目标未通过重伤豁免时会触发特殊能力或效果。

### 属性损失

- 如果玩家角色在战斗之外受到伤害，应改为让某项属性受损，通常是力量。
- 如果玩家角色的力量降至 0，他会死亡；如果敏捷降至 0，他会瘫痪；如果意志降至 0，他会神志错乱。敏捷和意志完全损失会使角色无法行动，直到通过长期休息或非凡手段恢复。

### 角色死亡

- 角色死亡后，玩家应创建一个新角色，或接管一名雇工。新角色会立刻加入队伍，以减少停摆时间。

### 分队

- 一大群相似的战斗者一起战斗时，可以视为一个**分队**。当一个**分队**受到**重伤**时，它会溃散或遭到严重削弱。当它的力量降至 0 时，就会被摧毁。
- 个体对分队的攻击会受到*削弱*（*爆发*伤害除外）。分队对个体的攻击会得到*强化*，并造成*爆发*伤害。

### 撤退

- 从危急情势中逃跑总是需要一次成功的敏捷豁免，同时还需要一个可以逃往的安全地点。

### 远程攻击

- 远程武器可以瞄准任何近到能看清其眼白的敌人。攻击特别遥远的目标时会受到*削弱*。
- 除非另有说明，否则不追踪弹药数量。

## 创伤 {#scars}

如果一次伤害会使玩家角色的 HP 恰好降至 0，就根据该次攻击损失的 HP 数量查阅下表。例如，如果玩家角色从 3 HP 降至 0 HP，就查阅第 3 项（击飞）。

## 魔法

### 法术书

- **法术书**包含一个法术，占用一个物品栏格。法术书无法轻易抄录或制作；它们通常是在坟墓、地下城和庄园等地方找到的。
- 法术书有时会表现出奇异的性质或限制，例如打开时散发恶臭或非人间的气味、拥有与生俱来的智慧，或只有在月光下才能阅读。
- 法术书会吸引那些觊觎其中奥术力量之人的注意；公开展示法术书通常被视为危险之举。

### 施放法术

- 任何人都可以双手拿着法术书，大声读出其中内容来施放法术。之后，他们必须在物品栏中增加一点**疲劳**。
- 如果有充足的时间且处于安全之中，玩家角色可以增强法术的效果（例如影响多个目标、提高法术力量等），而无需额外付出代价。
- 如果玩家角色处于*匮乏*状态或身处危险（例如战斗中），守望者可以要求玩家角色进行一次意志豁免，以避免施法带来的负面影响。失败的后果应与法术原本的效果相当，可能包括增加**疲劳**、摧毁法术书、受伤，甚至死亡。

### 卷轴

**卷轴**与法术书相似，但：

- 卷轴属于*低阶法术*。
- 卷轴不会造成**疲劳**。
- 卷轴使用一次后就会消失。

### 遗物

**遗物**是注入了魔法或法术力量的物品。遗物不会造成疲劳。遗物通常只能有限次使用，并且具有某种**充能**条件。
