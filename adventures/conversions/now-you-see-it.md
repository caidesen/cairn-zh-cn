# 现在你看见了…… {#now-you-see-it}

改编自 Mark Penn 与 Steve Wilson 创作的 [Now You See It...](https://drive.google.com/file/d/1AJX3rt0UteBElnSQW3sWPvUkyBC7HZ9p/view?usp=sharing)。

- 将 **Discerning Spirits** 检查视为 WIL 豁免。
- 将 **Tools and Talents**、**Dexterity** 与 **Alertness** 检查视为 DEX 豁免；如果角色拥有合适的背景，也可以通过角色扮演处理。

- **商队守卫/矿井守卫** 使用 Cairn 怪物图鉴中强盗的相同属性。
- **狼** 使用 Cairn 怪物图鉴中狼的相同属性。
